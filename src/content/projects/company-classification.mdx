## Overview

A multi-class text classification problem: given a free-text description of a company, predict the industry sector it belongs to. The pipeline combines pretrained GloVe word embeddings with a Keras model, with hyperparameter optimisation via `hyperas` and `hyperopt`.

The full analysis — preprocessing, training, and evaluation — lives in a single notebook (`analysis.ipynb`).
